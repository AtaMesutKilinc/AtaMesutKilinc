### 🛠️ What I work on

- 🧩 **Enterprise backend services** — identity management, employment and career services, event registration, utility expense calculation and institutional messaging workflows with Java and Spring Boot
- 🔐 **Authentication & authorization** — Spring Security, OAuth2, JWT and Keycloak: OTP-based onboarding, password reset, token lifecycle, single sign-on and machine-to-machine client management
- 📱 **Mobile API security** — Firebase App Check verification, device binding, Redis/DB-backed rate limiting and IP blocking against unauthorized access and brute-force attempts
- 🛡️ **Legacy hardening & privacy** — OWASP-based XSS sanitization, Apache Tika content-type validation, sensitive-data masking, consent and user-lifecycle processes supporting KVKK (Turkish GDPR)
- 🔗 **Integrations** — REST and SOAP services for identity verification, tax authority, SMS and push notifications
- ⏱️ **Background processing** — scheduled and distributed jobs with Spring Scheduling and ShedLock for data synchronization, consent processing and business automation
- 🗄️ **Data & delivery** — Oracle and PostgreSQL with JPA/Hibernate and Flyway, Redis and Caffeine for caching and temporary state; Docker, Kubernetes and GitLab CI deployments

### 🧪 Earlier work

- 🩺 Spring Boot service for application heartbeat monitoring; LDAP integration, validation and database configuration
- ☁️ Spring and React deployments on OpenShift; research on blockchain, cryptography and self-sovereign identity
- 👁️ Real-time computer vision prototypes for emotion analysis and multi-object tracking with Python, OpenCV, TensorFlow, Keras, YOLO, Mask R-CNN and Deep SORT

### 🤖 AI-Assisted Engineering

Daily use of **Codex, ChatGPT, Claude and Gemini** — agentic development workflows, MCP integrations, reusable skills and plugins,
codebase analysis, refactoring, test generation, documentation and developer automation.
